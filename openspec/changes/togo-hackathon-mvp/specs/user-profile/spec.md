# Spec Delta

## Purpose

Описывает пользователя ToGo: его имя, город и интересы, чтобы люди понимали, с кем встретятся, а лента могла
подсказывать подходящие события.

## ADDED Requirements

### Requirement: Справочник интересов

Система ДОЛЖНА (SHALL) предоставлять фиксированный справочник интересов, у каждого из которых есть идентификатор и
название. На справочник ссылаются профили и события. Справочник ДОЛЖЕН (SHALL) быть доступен без входа.

#### Scenario: Клиент загружает справочник

- **WHEN** посетитель запрашивает список интересов
- **THEN** система возвращает все интересы с идентификаторами и названиями, например «Кафе», «Спорт», «Выставки», «Кино»
  и «Настольные игры»

### Requirement: Редактирование своего профиля

Система ДОЛЖНА (SHALL) позволять вошедшему пользователю указать имя, город и набор интересов из справочника. Имя и город
НЕ ДОЛЖНЫ (MUST NOT) быть пустыми. Набор интересов может быть пустым.

#### Scenario: Пользователь заполняет профиль

- **GIVEN** вошедший пользователь
- **WHEN** пользователь сохраняет город «Санкт-Петербург» и интересы «Кино» и «Настольные игры»
- **THEN** в профиле указан этот город и ровно эти два интереса

#### Scenario: Неизвестный интерес

- **WHEN** вошедший пользователь сохраняет профиль с идентификатором интереса, которого нет в справочнике
- **THEN** система отклоняет изменение с ошибкой валидации, указывающей на поле интересов

#### Scenario: Пустой город

- **WHEN** вошедший пользователь сохраняет профиль с пустым городом
- **THEN** система отклоняет изменение с ошибкой валидации, указывающей на поле города

### Requirement: Просмотр чужого профиля

Система ДОЛЖНА (SHALL) позволять вошедшему пользователю видеть имя, фото, город и интересы другого пользователя.
Идентификатор и username Telegram другого пользователя НЕ ДОЛЖНЫ (MUST NOT) показываться.

#### Scenario: Пользователь смотрит профиль участника

- **GIVEN** пользователь «Борис» с username Telegram «boris_m», городом «Москва» и интересом «Спорт»
- **WHEN** вошедший пользователь открывает профиль Бориса
- **THEN** система возвращает имя «Борис», фото, город «Москва» и интерес «Спорт», но не username «boris_m» и не
  идентификатор Telegram

#### Scenario: Профиль не существует

- **WHEN** вошедший пользователь открывает профиль с неизвестным идентификатором
- **THEN** система отвечает ошибкой «не найдено»
