# Spec Delta

## Purpose

Помогает найти событие, к которому стоит присоединиться: лента предстоящих событий, фильтры по интересу, городу, времени
и свободным местам, подробная карточка события и карта событий.

## ADDED Requirements

### Requirement: Лента событий

Система ДОЛЖНА (SHALL) показывать любому посетителю, вошедшему или нет, ленту неначавшихся и неотменённых событий по
возрастанию времени начала. Каждая запись ДОЛЖНА (SHALL) содержать название, интерес, город, время начала, число
участников, лимиты, статус и точку на карте, если она есть.

#### Scenario: Лента скрывает прошедшие и отменённые события

- **GIVEN** событие, которое начнётся завтра, событие, которое началось вчера, и отменённое событие, которое должно было
  начаться завтра
- **WHEN** посетитель открывает ленту
- **THEN** в ленте только событие, которое начнётся завтра

#### Scenario: Порядок ленты

- **GIVEN** событие, которое начнётся через три дня, и событие, которое начнётся завтра
- **WHEN** посетитель открывает ленту
- **THEN** первым идёт событие, которое начнётся завтра

### Requirement: Фильтры ленты

Система ДОЛЖНА (SHALL) сужать ленту по любому сочетанию фильтров, которые должны выполняться одновременно: один или
несколько интересов, город без учёта регистра букв, диапазон времени начала от самого раннего до самого позднего
момента, только события со свободными местами.

#### Scenario: Фильтр по интересу

- **GIVEN** предстоящие события с интересами «Спорт» и «Кино»
- **WHEN** посетитель фильтрует ленту по интересу «Кино»
- **THEN** в ленте только событие с интересом «Кино»

#### Scenario: Фильтр по городу не учитывает регистр

- **GIVEN** предстоящее событие в городе «Казань»
- **WHEN** посетитель фильтрует ленту по городу «казань»
- **THEN** в ленте есть это событие

#### Scenario: Фильтр по времени

- **GIVEN** предстоящие события в пятницу и в воскресенье
- **WHEN** посетитель фильтрует ленту по диапазону от субботы 00:00 до воскресенья 23:59
- **THEN** в ленте только воскресное событие

#### Scenario: Только события со свободными местами

- **GIVEN** заполненное предстоящее событие и предстоящее событие со свободным местом
- **WHEN** посетитель фильтрует ленту по наличию свободных мест
- **THEN** в ленте только событие со свободным местом

#### Scenario: Сочетание фильтров

- **GIVEN** предстоящие события с интересом «Спорт» в «Москве» и в «Казани»
- **WHEN** посетитель фильтрует по интересу «Спорт» и городу «Москва»
- **THEN** в ленте только событие «Спорт» в «Москве»

#### Scenario: Начало диапазона позже его конца

- **WHEN** посетитель фильтрует по диапазону, самый ранний момент которого позже самого позднего
- **THEN** система отклоняет запрос с ошибкой валидации, указывающей на диапазон времени

### Requirement: Карточка события

Система ДОЛЖНА (SHALL) показывать любому посетителю, вошедшему или нет, полную карточку любого события, включая
прошедшие и отменённые: название, описание, интерес, город, адрес, время начала, точку на карте, имя организатора, число
участников, лимиты, число свободных мест и статус.

#### Scenario: Посетитель открывает карточку

- **GIVEN** предстоящее событие «Настолки в антикафе» с максимумом 6 и 4 участниками, организованное Анной
- **WHEN** посетитель открывает его карточку
- **THEN** в карточке все поля события, организатор «Анна», 4 участника и 2 свободных места

#### Scenario: Неизвестное событие

- **WHEN** посетитель открывает карточку с неизвестным идентификатором события
- **THEN** система отвечает ошибкой «не найдено»

### Requirement: События на карте

Клиент ДОЛЖЕН (SHALL) показывать отфильтрованную ленту на карте: ставить маркер для каждого события с точкой на карте и
пропускать события без неё. Выбор маркера ДОЛЖЕН (SHALL) открывать карточку этого события.

#### Scenario: Карта показывает события с точкой

- **GIVEN** два предстоящих события, одно с точкой на карте, другое без
- **WHEN** посетитель открывает карту
- **THEN** на карте один маркер, для события с точкой

#### Scenario: Маркер ведёт к карточке

- **WHEN** посетитель выбирает маркер на карте
- **THEN** клиент открывает карточку этого события
