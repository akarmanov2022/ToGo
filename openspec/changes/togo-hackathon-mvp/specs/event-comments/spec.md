# Spec Delta

## Purpose

Даёт участникам простое место под событием, чтобы договориться о деталях встречи: где именно встретиться или что взять с
собой.

## ADDED Requirements

### Requirement: Публикация комментария

Система ДОЛЖНА (SHALL) позволять участнику события, включая организатора, оставить комментарий через
`POST /api/v1/events/{eventId}/comments` в любом состоянии события. Текст НЕ ДОЛЖЕН (MUST NOT) быть пустым
или состоять из пробелов и ДОЛЖЕН (MUST) содержать не больше 1000 символов. Сервер ДОЛЖЕН (SHALL) ответить 201
с комментарием. Комментарии НЕЛЬЗЯ (MUST NOT) редактировать или удалять.

#### Scenario: Участник оставляет комментарий

- **GIVEN** Борис участвует в событии
- **WHEN** Борис публикует «Встречаемся у входа в 18:50»
- **THEN** сервер отвечает 201 с комментарием, автором Борисом и временем публикации

#### Scenario: Комментировать пытается не участник

- **GIVEN** Вера вошла в систему и не участвует в событии
- **WHEN** Вера пытается оставить под ним комментарий
- **THEN** сервер отвечает 403 FORBIDDEN

#### Scenario: Пустой комментарий

- **WHEN** участник публикует комментарий, состоящий только из пробелов
- **THEN** сервер отвечает 400 VALIDATION_ERROR с полем `text`

#### Scenario: Слишком длинный комментарий

- **WHEN** участник публикует комментарий длиной 1001 символ
- **THEN** сервер отвечает 400 VALIDATION_ERROR с полем `text`

#### Scenario: Комментарий к неизвестному событию

- **WHEN** пользователь публикует комментарий к неизвестному событию
- **THEN** сервер отвечает 404 EVENT_NOT_FOUND

### Requirement: Чтение комментариев

Система ДОЛЖНА (SHALL) отдавать комментарии к событию любому вошедшему пользователю через
`GET /api/v1/events/{eventId}/comments` страницами `limit` и `offset`, от старых к новым, с автором, текстом
и временем публикации.

#### Scenario: Вошедший пользователь читает комментарии

- **GIVEN** у события есть комментарий Анны, опубликованный в 10:00, и комментарий Бориса, опубликованный в 10:05
- **WHEN** вошедший пользователь открывает комментарии к событию
- **THEN** комментарий Анны идёт перед комментарием Бориса, `total` равен 2

#### Scenario: Анонимный посетитель читает комментарии

- **WHEN** клиент запрашивает комментарии без токена
- **THEN** сервер отвечает 401 UNAUTHORIZED
