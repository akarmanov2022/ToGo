# ToGo
ToGo - мини-приложение в Telegram для поиска компании и совместного досуга. Пользователи создают события (кофе, выставка, пробежка, кино, настолки) или присоединяются к уже существующим. Компанию можно найти по интересам, месту и времени, а место выбирается на карте Санкт-Петербурга. Название собрано из Together и Go: "просто пойти вместе".
