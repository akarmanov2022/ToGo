# Map

Текущее требование: `PlacePicker` выбирает **только существующее место из переданного списка**.
Значок-ссылка «Leaflet» в углу карты скрыт (`attributionControl.setPrefix(false)`); строка
«© OpenStreetMap contributors» остаётся — её требует лицензия тайлов.
Публичные экспорты: `PlacePicker` и тип `MeetingPlace { id, name, address, latitude, longitude, category }`.
Компонент принимает `places: MeetingPlace[]` и `v-model: MeetingPlace | null`.
Родитель задаёт список (пока локально, без API) и отвечает за дальнейшее использование выбранного места.

Все места показаны круглыми маркерами Leaflet; клик по маркеру или кнопке списка выбирает место.
Выбранный маркер и кнопка выделены, под картой показаны название и адрес без координат.
Произвольный клик по карте ничего не выбирает; ручного адреса и геокодирования нет.
При удалении выбранного места из `places` модель сбрасывается в `null`.
Список доступен с клавиатуры и остаётся рабочим при ошибке тайлов; есть повтор загрузки и восстановление сети.

`LocationPicker`, `Coordinates` и `toCoordinateFields` сохранены как прежний интерфейс для совместимости
и тестов; они не соответствуют новому сценарию выбора готовых мест. Для новых интеграций используйте `PlacePicker`.
